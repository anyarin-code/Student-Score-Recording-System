# Student Score Recording System

โปรแกรมบันทึกคะแนนนักเรียน พัฒนาด้วยภาษา Python

## ความสามารถ

- รับชื่อนักเรียน
- รับรหัสนักศึกษา
- รับชื่อวิชา
- รับคะแนน
- ตรวจสอบคะแนนให้อยู่ในช่วง 0-100
- คำนวณเกรด A-F
- ตรวจสอบผลการเรียนว่า ผ่าน / ไม่ผ่าน
- สามารถเพิ่มได้หลายวิชา

## เทคโนโลยีที่ใช้

- Python

## สิ่งที่ได้เรียนรู้

- การใช้ตัวแปร
- การรับข้อมูลด้วย 'Input()'
- การใช้ 'if / elif / else'
- การใช้ 'while loop'
- การตวรจสอบข้อมูลก่อนประมวลผล

## วิธีใช้งาน

1. เปิดไฟล์ 'student_score.py'
2. รันด้วย Python
3. กรอกชื่อและรหัสนักศึกษา
4. กรอกวิชาและคะแนน
5. โปรแกรมจะแสดงเกรดและผลการเรียน
6. เลือก 'y' เพื่อเพิ่มวิชา หรือ 'n' เพื่อจบโปรแกรม
